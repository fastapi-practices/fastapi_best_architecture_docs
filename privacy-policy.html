隐私政策

更新日期 2026/9/6·生效日期 2026/9/6

导言

本《隐私政策》由 wu-clan / FastAPI Practices（以下简称“我们”）就 fba（FastAPI Best Architecture）官方文档网站制定。 本政策说明我们如何收集、使用、存储、共享和保护与您有关的信息，以及您如何行使相关权利。

本政策仅适用于本网站及我们为提供本网站而使用的相关服务，不适用于您或其他主体自行部署、运营的 fba 项目。自行部署产生的数据处理，由相应运营者自行负责。

请您在使用本网站前仔细阅读本政策。继续访问或使用本网站，即表示您知悉并同意我们按照本政策处理相关信息。如您不同意，请停止使用本网站，并可通过浏览器设置拒绝 Cookie。

如对本政策或相关事宜有任何问题，请通过 jianhengwu0407@gmail.com 与我们联系。

1. 我们收集的信息

本网站是面向开发者的开源文档站点，不提供用户注册、登录或账号体系，也不会主动收集电话号码、身份证号、生物识别等个人敏感信息。我们仅在实现下列目的所必需的范围内处理信息：

1.1 您主动提供的信息

  • 联系信息：当您通过电子邮件与我们联系时，我们会收到您的邮箱地址及邮件内容，用于答复咨询。
  • 社区互动信息：当您通过本网站评论（Giscus）、GitHub Issue / Pull Request、用户登记等方式与我们互动时，相应平台会处理您的 GitHub 账号、昵称、头像及您公开发布的内容。上述信息由 GitHub 按其自身政策处理，我们仅在公开可见范围内使用。

1.2 自动收集的信息

  • 访问日志：网站托管服务可能记录访问时间、请求路径、浏览器类型、设备与操作系统信息、来源页面及 IP 地址，用于保障站点可用、排查故障和安全防护。
  • 统计分析信息：我们使用百度统计了解页面访问量、来源和大致使用情况，可能通过 Cookie、匿名标识符收集设备信息、浏览页面、访问时长等，用于改进文档内容和站点体验。百度统计由百度运营，适用其隐私政策。

1.3 仅保存在您设备本地的信息

  • 本网站可能使用浏览器 localStorage 缓存插件市场列表、项目统计等公开数据，以减少重复请求。此类数据保存在您的设备上，不会因此单独上传至我们的服务器。您可随时在浏览器中清除。

2. 我们如何使用信息

我们仅将收集的信息用于以下目的：

  • 提供、维护和改进本网站及文档内容；
  • 统计访问情况，了解文档使用效果；
  • 答复您的咨询、意见或权利请求；
  • 保障网站安全、排查故障、防止滥用；
  • 履行法律法规规定的义务。

我们不会将您的信息用于个性化广告投放，也不会向广告主出售您的个人信息。

3. Cookie 与同类技术

本网站及第三方服务可能使用 Cookie 或同类技术：

  • 必要或功能类：用于语言偏好、主题、本地缓存等基本浏览功能；
  • 统计类：百度统计使用 Cookie 或标识符生成访问统计。

您可以通过浏览器设置拒绝或删除 Cookie。拒绝后，部分统计功能将无法完成，一般不影响阅读文档。清除浏览器数据也会删除本地缓存。

4. 信息的存储

4.1 存储方式和期限

  • 您发送的邮件等联系信息，我们仅在处理咨询、完成权利请求或履行法定义务所需的期限内保存，到期后删除或匿名化处理。
  • 访问日志、统计数据的保存期限分别遵循托管服务商和百度统计的规则，我们不会另行无限期留存。
  • 您设备上的本地缓存由您自行控制，可随时清除。

4.2 存储地点

  • 本网站部署于境外托管平台，访问日志可能存储于境外。
  • 百度统计相关数据由其在境内处理。
  • 评论、代码托管和协作发生在 GitHub 等境外平台。

5. 委托处理、共享与第三方服务

为提供本网站，您的浏览器可能向以下第三方发送必要请求。我们不会出售您的个人信息。

  • 网站托管：Vercel 等托管服务商处理访问请求与访问日志，用于内容分发和安全保障；
  • 百度统计：用于访问统计分析；
  • GitHub / Giscus：用于源码托管、文档评论和社区协作；
  • 内容分发：部分图片、插件列表或统计数据可能通过 GitHub、jsDelivr 等 CDN 加载；
  • 展示性赞助内容：本网站可能展示赞助商信息或素材，属于公开展示，我们不会为此向赞助商提供可识别您个人身份的信息。

您点击跳转到 GitHub、Discord 等外部网站后，适用该第三方自己的隐私政策，我们对其处理行为不承担责任。

根据法律法规，在下列情形中，我们可能在无需另行征得同意的情况下提供信息：与国家安全、公共安全、刑事司法等直接相关；为保护您或他人重大合法权益但又难以获得本人同意；您自行公开或从合法公开渠道收集且不违反您的重大利益；法律、行政法规规定的其他情形。

6. 跨境提供

由于本网站托管、评论和开源协作使用境外服务，您访问本网站、发表评论或通过 GitHub 与我们互动时，相关信息（如 IP 地址、设备信息、GitHub 账号及公开内容）可能被传输至中华人民共和国境外。 跨境提供是为了向您提供文档访问、评论和开源协作功能。如您不希望发生上述传输，请停止使用相应功能。

7. 信息安全

我们采取合理可行的技术与管理措施保护信息安全，例如使用 HTTPS 传输。同时请理解，任何互联网传输和存储都无法保证百分之百安全。请您妥善保管自己的 GitHub 账号、邮箱等凭证，避免在本网站或公共渠道提交不必要的个人敏感信息。

8. 您的权利

在适用的法律法规范围内，您对个人信息享有查阅、复制、更正、删除、限制或拒绝处理、撤回同意等权利。由于本网站无用户账号，上述请求请通过 jianhengwu0407@gmail.com 提出，并说明具体请求内容以便我们核实后处理。

  • 您可自行清除浏览器 Cookie 和本地缓存；
  • 您可停止使用本网站，或通过浏览器拦截统计脚本和第三方请求；
  • 您在 GitHub / Giscus 上的内容，可按 GitHub 账户设置和相应页面功能自行管理。

我们将在核实身份后及时答复。如您认为我们的处理损害了您的合法权益，还可以向网信、工信、市场监管等有权部门投诉或举报。

9. 未成年人保护

本网站主要面向软件开发者，不以不满十四周岁的未成年人为目标用户，也不会主动收集其个人信息。 如您是监护人，发现未成年人未经同意向我们提供了个人信息，请通过上述邮箱联系我们，我们将及时删除相关信息。

10. 政策变更

我们可能根据业务、技术或法律变化修订本政策。更新后，我们将在本页面公布修订后的政策，并更新文首的生效日期。 重大变更时，我们会以页面提示等合理方式告知。如您在政策更新后继续使用本网站，即表示您同意更新后的政策。
