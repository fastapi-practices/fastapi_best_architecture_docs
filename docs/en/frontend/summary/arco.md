<p style="color: red;">This version is no longer updated or maintained! The related code repository has been archived!</p>

On March 29, 2025, we archived the Arco repository. It will no longer receive any updates. Making this decision was not easy — Arco carried countless explorations and expectations — but technology never stands still. To meet more efficient, modern needs, we must move on.

Thank you for everyone's support. Please join us in opening a new chapter with [Vben Admin Antd](intro.md).

::: note
This implementation hard-coded Casbin RBAC authorization. To decouple it, manually remove Casbin, API management, and all related calls.
:::

::: caution
As of v1.0.4, this implementation has completed its mission. Later fba versions no longer adapt to it. Do not use it in production!
:::
